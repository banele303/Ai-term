# AutoPulse QuoteCraft AI Skill

This skill defines the quotation and deal architecture for AutoPulse AI: generating formal, branded, South African VAT-compliant PDF quotes, managing CRM deals, and dispatching quotes across WhatsApp and Email.

## 1. Quotation Specification & Standards

Every quote generated by QuoteCraft AI must adhere to the following South African automotive trade standards:

- **Currency:** South African Rand (`ZAR`). Formatted as `ZAR 3,850.00`.
- **Value Added Tax (VAT):** 15% South African VAT calculated on subtotal:
  $$\text{VAT} = \text{Subtotal} \times 0.15$$
  $$\text{Grand Total} = \text{Subtotal} + \text{VAT} + \text{Core Deposits}$$
- **Quotation Validity:** Guaranteed 14-day price lock from date of issue.
- **Reference Code:** Standard format `QT-YYYY-XXXX` or `QT-<DEAL_ID_LAST_6>`.
- **Payment Link:** Built dynamically as `/pay/{dealId}` (or absolute URL `${APP_URL}/pay/{dealId}`).
- **Banking / EFT Details:** Standard trade banking instructions (FNB / Standard Bank / Capitec Pay).
- **Logistics Terms:** The Courier Guy priority overnight express (24-48 hours nationwide).

## 2. Data Model & Convex Mutations

### Creating a Deal and Quote
Call `api.crm.createQuoteAndDeal`:

```typescript
const result = await createQuoteAndDealMut({
  clientName: "Apex Commercial Fleet",
  clientEmail: "workshop@apexautos.co.za",
  clientPhone: "+27 82 459 1044",
  companyName: "Apex Autos Ltd",
  dealTitle: "Fleet Replacement: Hilux Alternators & Braking",
  vehicleMake: "Toyota",
  vehicleModel: "Hilux 2.8 GD-6",
  vehicleYear: 2022,
  vehicleVin: "AHTBA3CD409128456",
  notes: "Urgent commercial fleet quote with 14-day price guarantee.",
  validUntilDays: 14,
  items: [
    {
      sku: "BOS-ALT-140A",
      description: "Bosch 140A Alternator (OEM Spec)",
      quantity: 2,
      unitPrice: 3850,
    },
    {
      sku: "FER-BRK-D440",
      description: "Ferodo Premier Heavy-Duty Front Brake Pads",
      quantity: 2,
      unitPrice: 1250,
    },
  ],
});

// Returns: { dealId, quoteReference, totalAmount, currency, paymentLink }
```

## 3. Multi-Channel Dispatch

### WhatsApp Dispatch (Whapi.cloud)
Call `api.whapi.staffSend`:

```typescript
await staffSendWhapiAction({
  to: clientPhone,
  body: `*OFFICIAL QUOTATION • AUTOPULSE AUTO PARTS*
📋 *Quote Ref:* ${quoteNumber}
🚗 *Vehicle:* ${vehicleYear} ${vehicleMake} ${vehicleModel}
💰 *TOTAL:* ZAR ${total.toLocaleString()} (Incl. 15% VAT)
💳 *Review & Pay Online:* ${paymentLink}`,
});
```

### Email Dispatch (Composio Gmail / SMTP)
Call `api.teammates.recordCustomerOutreach`:

```typescript
await recordCustomerOutreachMut({
  recipient: clientEmail,
  channel: "email",
  subject: `AutoPulse Quotation #${quoteNumber} for ${clientName}`,
  body: emailBody,
  quoteRef: quoteNumber,
});
```

## 4. Automated 3-Stage Follow-Up Sequence

When quotes are pending in `quote_sent` or `lead` status:

1. **24-Hour Stock Hold Reminder:**
   Alerts the customer that the quoted parts are reserved at the distribution hub for 24 hours.
2. **48-Hour Technical Fitment Verification:**
   Informs the workshop/customer that an OEM master technician has reviewed the VIN and confirmed 100% fitment compatibility.
3. **72-Hour Price Guarantee Expiration:**
   Notifies the client that the 14-day distributor price guarantee will lapse due to supplier price adjustments.
